# Задача для Claude Code: open-source музыкальный плеер в стиле Liquid Glass

Ты — ведущий разработчик проекта. Нужно с нуля создать **кроссплатформенный open-source десктопный музыкальный плеер** под названием **Vitra** в визуальном стиле **Liquid Glass** (вдохновлён Apple Music), с **полной кастомизацией** интерфейса и тем, поддержкой **любых аудиоформатов**, **воспроизведением по ссылкам** (YouTube и др. — только аудио) и **текстами песен** (встроенные, синхронизированные, свои).

Работай **поэтапно** (этапы в конце документа). Перед началом составь план, создай `CLAUDE.md` с ключевыми решениями и структурой проекта и покажи мне план. Если что-то неоднозначно — спроси меня, а не угадывай.

Общение со мной — на русском. Код, комментарии, коммиты, README — на английском.

## 1. Стек

| Слой | Технология | Зачем |
|---|---|---|
| Оболочка приложения | **Tauri 2** (последняя стабильная), Rust | Лёгкие сборки под macOS / Windows / Linux, прозрачные окна, несколько окон, трей |
| Интерфейс | **React + TypeScript + Vite** | Вся кастомизация и стекло делаются на CSS |
| Состояние | Zustand | Простое глобальное состояние |
| Стили | CSS Modules + **CSS-переменные** (вся тема = набор переменных) | Темы меняются без пересборки |
| Анимации | Motion (framer-motion) | Плавные переходы, как в Apple Music |
| Иконки | Lucide | Свои иконки, никаких ассетов Apple |
| Воспроизведение | **mpv** как sidecar-процесс, управление через JSON IPC (`--idle --input-ipc-server`) | Играет практически любой формат, gapless, ReplayGain, эквалайзер через lavfi, стримы |
| Ссылки | **yt-dlp** как sidecar (mpv вызывает его через ytdl_hook, `--ytdl-format=bestaudio`, видео отключено) | YouTube, YouTube Music, SoundCloud и сотни сайтов |
| Скачивание и конвертация | **FFmpeg** как sidecar (используется yt-dlp) | Извлечение аудио, конвертация, вшивание обложки и тегов |
| Теги и тексты | Rust crate **lofty** | Чтение/запись тегов, обложек, USLT/SYLT, Vorbis `LYRICS` |
| База библиотеки | SQLite (rusqlite) + FTS5 | Библиотека, плейлисты, тексты, быстрый поиск |
| Слежение за папками | crate `notify` | Автообновление библиотеки |
| Эффекты окна | crate `window-vibrancy` | macOS — NSVisualEffectView, Windows 11 — Mica/Acrylic |
| Медиаклавиши / Now Playing | crate `souvlaki` | macOS Now Playing, Windows SMTC, Linux MPRIS |
| Хоткеи | `tauri-plugin-global-shortcut` | Глобальные горячие клавиши |
| Валидация тем | zod + JSON Schema | Безопасный импорт чужих тем |
| Локализация | i18next | Русский и английский |
| Тесты | `cargo test`, Vitest | Парсер LRC, валидация тем, логика очереди |
| CI / релизы | GitHub Actions + `tauri-action` | Автосборки под 3 ОС при создании тега |
| Лицензия | **GPL-3.0** | Совместимо с mpv |

Основная платформа разработки — **macOS (Apple Silicon)**, но всё должно собираться и работать на Windows x64 и Linux. Sidecar-бинарники mpv, yt-dlp и FFmpeg скачиваются скриптом (`scripts/fetch-sidecars`) под нужную платформу, в репозиторий не коммитятся.

Не добавляй тяжёлые зависимости без необходимости; если добавляешь — коротко объясни зачем.

## 2. Визуальный стиль Liquid Glass

- Полупрозрачные «стеклянные» слои: размытие и усиление насыщенности фона, тонкая светлая обводка, блик по краю (specular highlight), мягкая тень, лёгкая рефракция (искажение фона по краям).
- Реализуй как переиспользуемый компонент `<Glass>` с параметрами: `blur`, `saturation`, `tint`, `opacity`, `radius`, `border`, `highlight`, `refraction`. Все значения по умолчанию берутся из CSS-переменных темы.
- Рефракция — через SVG `feDisplacementMap` в `backdrop-filter` там, где движок это поддерживает (WebView2/Chromium на Windows). В WebKit (macOS) и на Linux — **автоматический fallback** на blur + блик. Определяй поддержку feature detection'ом, а не по ОС.
- Окно приложения прозрачное с системной вибрацией (`window-vibrancy`).
- Фон главного экрана — размытая обложка текущего трека и медленно перетекающий градиент из её доминирующих цветов. Акцентный цвет интерфейса автоматически берётся из обложки (можно отключить или зафиксировать в теме).
- Учитывать системные настройки «уменьшить движение» и «уменьшить прозрачность» + свои переключатели в настройках.
- Производительность: стабильные 60 fps, ограничь количество одновременно активных слоёв с `backdrop-filter`, тяжёлые эффекты отключаются в режиме энергосбережения.
- **Не копировать** иконки, логотипы, шрифты и прочие ассеты Apple — только стиль.

## 3. Кастомизация

### Темы
- Тема = `theme.json` (цвета, параметры стекла, шрифты, радиусы, отступы, фон, анимации, опционально раскладка) + опциональный `custom.css` + ассеты (фоновые картинки, шрифты), упакованные в zip с расширением `.vitratheme`.
- Схема темы описана JSON Schema (`docs/theme.schema.json`) и проверяется при импорте. Темы **не могут содержать JavaScript**.
- Импорт: перетащить файл в окно / кнопка в настройках. Экспорт: одна кнопка → файл, которым можно поделиться.
- Встроенный **редактор тем** с живым превью: палитра, ползунки стекла (размытие, прозрачность, блик, рефракция), шрифты, скругления, фон.
- Встроенные темы: Light, Dark, Auto (по системе) и 2–3 примера в папке `/themes` репозитория.

### Раскладка интерфейса
- Интерфейс собран из модулей: сайдбар, библиотека, очередь, панель текста, большая обложка, нижняя панель управления, мини-визуализация громкости и т.д.
- Модули можно включать/выключать, перетаскивать и менять размер (dnd-kit), сохранять как пресет раскладки; пресет можно включить в тему.
- Переназначаемые горячие клавиши.

### Задел на плагины
- Внутри приложения используй шину событий (track changed, play/pause, lyrics line и т.д.), чтобы в будущем можно было добавить API плагинов. Сами плагины в первой версии **не реализовывать** — только архитектура и пункт в roadmap.

## 4. Мини-плеер

- Отдельное окно Tauri, открывается кнопкой, из трея или горячей клавишей.
- Режимы: компактный (обложка + кнопки + прогресс), узкая полоска, «только текст» (текущая строка песни, караоке-стиль).
- Настройки: **поверх всех окон / обычное окно**, прозрачность, размер, привязка к краям экрана, запоминание позиции, опциональный «клик насквозь».
- Мини-плеер тоже в стиле Liquid Glass и подчиняется текущей теме.

## 5. Воспроизведение

- **Форматы** — всё, что умеет mpv/FFmpeg: MP3, FLAC, ALAC, AAC/M4A, OGG Vorbis, Opus, WAV, AIFF, APE, WavPack, WMA, DSD (DSF/DFF) и т.д.
- **Локальные источники**: файлы и папки (drag & drop, диалог открытия), отслеживаемые папки библиотеки.
- **Ссылки**: YouTube, YouTube Music, SoundCloud, прямые ссылки на аудиофайлы, интернет-радио (m3u/pls/прямой поток). Если ссылка ведёт на видео — играть **только аудио**, видео не загружать. Метаданные (название, автор, обложка-превью, длительность) получать через `yt-dlp -J`. Ссылка на плейлист → импорт как плейлист.
- **Скачивание трека по ссылке в библиотеку**:
  - кнопка «Скачать» у трека из ссылки и у импортированного плейлиста (скачать весь плейлист);
  - формат на выбор: оригинал без перекодирования (обычно Opus или M4A — лучшее качество, по умолчанию), либо конвертация в MP3 (выбор битрейта) или FLAC;
  - автоматически вшиваются обложка и теги (название, исполнитель, альбом, год) из метаданных источника; если для трека уже есть текст в базе — он тоже записывается в теги;
  - папка загрузок настраивается, шаблон имени файла (по умолчанию `Исполнитель - Название`);
  - очередь загрузок с прогрессом, отменой и повтором при ошибке; скачанный трек сразу появляется в библиотеке, а запись о стриминговом треке заменяется на локальную (плейлисты, тексты и счётчик прослушиваний сохраняются);
  - через yt-dlp (`-x`, `--embed-thumbnail`, `--embed-metadata`) + FFmpeg.
- Кнопка «обновить yt-dlp» в настройках (yt-dlp часто ломается из-за изменений сайтов).
- Gapless, настраиваемый crossfade, ReplayGain, нормализация громкости.
- 10-полосный эквалайзер с пресетами и сохранением своих (через фильтры mpv/lavfi).
- Скорость воспроизведения.
- Очередь: «играть далее», «добавить в конец», перетаскивание, shuffle, repeat (один / все), история прослушиваний.
- Восстановление сессии после перезапуска (очередь, позиция, громкость).

## 6. Тексты песен

### Источники (в порядке приоритета)
1. Синхронизированный текст в тегах файла (ID3 `SYLT`; Vorbis/FLAC `LYRICS` или `SYNCEDLYRICS` в формате LRC; MP4 `©lyr` с LRC-таймкодами).
2. Файл `.lrc` рядом с треком с тем же именем.
3. Несинхронизированный текст в тегах (`USLT` / `LYRICS`).
4. Текст, сохранённый пользователем в базе приложения (в том числе для треков из ссылок).
5. Онлайн: **LRCLIB** (lrclib.net, открытый API) — выключено по умолчанию, включается в настройках, результаты кэшируются.

### Отображение (как в Apple Music)
- Плавная автопрокрутка, текущая строка подсвечена и увеличена, остальные приглушены/размыты.
- Клик по строке — перемотка к ней.
- Поддержка enhanced LRC (тайминги на каждое слово) с караоке-подсветкой слов.
- Несинхронизированный текст — просто прокручиваемый текст.
- Опционально вторая дорожка — перевод строк под оригиналом.
- Регулировка размера шрифта и сдвига синхронизации «на лету».

### Редактор текста
- Вставить или написать текст для любого трека.
- Режим синхронизации «тапом»: трек играет, пользователь жмёт пробел в начале каждой строки; можно откатить строку, сдвинуть все тайминги.
- Сохранение на выбор: в теги файла (с подтверждением и резервной копией), в `.lrc` рядом с файлом, или только в базу приложения.
- Экспорт/импорт `.lrc`.
