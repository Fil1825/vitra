# Third-party components in Vitra packages

Vitra is licensed under [GPL-3.0-or-later](../LICENSE). Bundled executables are GPLv2+/GPLv3-compatible; this file lists what ships in installers and where to obtain corresponding source.

## Runtime sidecars (per platform manifest)

Each release asset `*.manifest.json` records downloaded file names, URLs, SHA-256 checksums, and (where applicable) provenance labels. Install **Settings → About → Diagnostics** shows which helpers the running app found.

## Distribution obligation (GPL) — incomplete checklist

Manifests and this file **do not** by themselves satisfy corresponding-source obligations for every byte in installers.

| Status                                      | What we record today                                                                       | What a formal release still owes                                                                                                                                        |
| ------------------------------------------- | ------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Vitra app                                   | This Git repository at the release tag                                                     | Offer of source (GPL-3.0) for the exact tag                                                                                                                             |
| yt-dlp / FFmpeg / Deno                      | Pinned URLs + SHA-256 in `manifest.json`                                                   | Upstream source offers per their licenses                                                                                                                               |
| mpv (Apple Silicon / Windows)               | Official GitHub release URLs                                                               | mpv **0.41** source at matching tag                                                                                                                                     |
| mpv (**Intel, source build**)               | `intel-mpv-sources.json` + `build-intel-mpv.sh` + tarball shipped with the Intel installer | Built on the Intel release runner. Mach-O min OS is checked at build time. Playback on a real Monterey machine is still not hardware-verified.                          |
| mpv (Apple Silicon / Windows) / BtbN FFmpeg | Official or BtbN release asset + SHA-256                                                   | Upstream projects publish source. This repository does **not** rebuild those binaries, so their dependency closures are the upstream build’s, not Vitra’s Intel recipe. |

Release maintainers must complete Intel mpv provenance in release notes and manifests before claiming GPL redistribution compliance.
