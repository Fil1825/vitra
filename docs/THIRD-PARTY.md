# Third-party components in Vitra packages

Vitra is licensed under [GPL-3.0-or-later](../LICENSE). Bundled executables are GPLv2+/GPLv3-compatible; this file lists what ships in installers and where to obtain corresponding source.

## Runtime sidecars (per platform manifest)

Each release asset `*.manifest.json` records downloaded file names, URLs, SHA-256 checksums, and (where applicable) provenance labels. Install **Settings → About → Diagnostics** shows which helpers the running app found.

| **mpv** (macOS/Windows in bundle; Linux system package) | GPLv2+                                                        | macOS builds mpv **0.41.0** from `scripts/release/build-intel-mpv.sh`. Apple Silicon uses `macos-arm64-mpv-sources.json` (`MACOSX_DEPLOYMENT_TARGET=14.0`). Intel uses `intel-mpv-sources.json` (`MACOSX_DEPLOYMENT_TARGET=12.0`). ## Distribution obligation (GPL) — incomplete checklist

Manifests and this file **do not** by themselves satisfy corresponding-source obligations for every byte in installers.

| Status                         | What we record today                                                                                                                                  | What a formal release still owes                                                                                                                                                                                            |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Vitra app                      | This Git repository at the release tag                                                                                                                | Offer of source (GPL-3.0) for the exact tag                                                                                                                                                                                 |
| yt-dlp                         | Git tag archive, mutagen 1.48.1 sdist, PyInstaller 6.22.0 sdist, and CentOS `readline-6.2-11.el7.src.rpm` (vault SHA-256)                             | libintl, libidn2, and libunistring are named in yt-dlp's license text and are not files in `yt-dlp_linux`. The manylinux image that built it logged `Cannot find libidn2`.                                                  |
| FFmpeg (all four platforms)    | Official 7.1.1 tarball, checked by sha256 inside the source recipe                                                                                      | No external codec libraries. libiconv, aom, ffnvcodec, lame, opencore-amr, soxr, and xvid are not linked. lame r7113 and xvid r2204 had no stable official archive of that revision.                                         |
| mpv (macOS)                    | `build-intel-mpv.sh` plus the arch pins, `mach-minos.py`, and `mach-deps.py`                                                                          | Apple Silicon deployment target 14.0. Intel deployment target 12.0. Playback on a real Monterey machine is still not hardware-verified.                                                                                     |
| mpv (Windows)                  | `build-windows-mpv.sh` and `windows-mpv-sources.json`                                                                                                 | shaderc and its SPIR-V/glslang revisions are pinned commits. Vulkan-Headers and Vulkan-Loader are tag `vulkan-sdk-1.4.363.0` with `UPDATE_DEPS=OFF`.                                                                        |

The release workflow's prepare job uploads an Actions artifact. `publish-reused` refuses a GitHub Release. The previous installer zips are superseded because they do not match this source plan. New artifact ids are recorded only after those jobs finish. `complete` stays false on the old offers; the shipped programs are the source recipes above, not those offers.
