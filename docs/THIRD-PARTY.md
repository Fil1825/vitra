# Third-party components in Vitra packages

Vitra is licensed under [GPL-3.0-or-later](../LICENSE). Bundled executables are GPLv2+/GPLv3-compatible; this file lists what ships in installers and where to obtain corresponding source.

## Runtime sidecars (per platform manifest)

Each release asset `*.manifest.json` records downloaded file names, URLs, SHA-256 checksums, and (where applicable) provenance labels. Install **Settings → About → Diagnostics** shows which helpers the running app found.

## Distribution obligation (GPL) — incomplete checklist

Manifests and this file **do not** by themselves satisfy corresponding-source obligations for every byte in installers.

| Status                         | What we record today                                                                                                                                        | What a formal release still owes                                                                                                                                                                                                                                                        |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Vitra app                      | This Git repository at the release tag                                                                                                                      | Offer of source (GPL-3.0) for the exact tag                                                                                                                                                                                                                                             |
| yt-dlp                         | Git tag archive, mutagen 1.48.1 sdist, PyInstaller 6.22.0 sdist                                                                                             | Linux still needs pinned source for GNU Readline, libintl, libidn2, and libunistring                                                                                                                                                                                                    |
| FFmpeg (Windows / Linux, BtbN) | Build-script tag, FFmpeg commit archive, 78 GitHub archives, and 34 other commit archives whose refetched URL matched that tarball and a license file in it | Still no source archive: mingw, libiconv, xproto, aom, ffnvcodec, libdrm, lame, libvpx, libwebp, opencore-amr, soxr, and xvid. fdk-aac, whisper, and libcurl are not enabled for this GPL build. aom, libvpx, and libwebp were not recorded: a refetch did not match the scratch bytes. |
| FFmpeg (macOS, Martin Riedl)   | Pinned 9.0.2 zips and the publisher SHA-256 (not `redirect/latest`)                                                                                         | No tag on the public build-script repo matches this binary, and x264 is an unpinned 0.165.x. Not shipped as corresponding source.                                                                                                                                                       |
| mpv (Apple Silicon / Windows)  | Official GitHub release URLs                                                                                                                                | v0.41.0 macOS CI uses unpinned Homebrew; the Windows script clones shaderc at `HEAD` and turns on Vulkan `UPDATE_DEPS`. Not the binaries' corresponding source.                                                                                                                         |
| mpv (**Intel, source build**)  | `intel-mpv-sources.json` + `build-intel-mpv.sh` + `mach-minos.py` + `mach-deps.py` + tarball shipped with the Intel installer                               | Built on the Intel release runner. Mach-O min OS is checked at build time. Playback on a real Monterey machine is still not hardware-verified.                                                                                                                                          |

The release workflow's prepare job uploads an Actions artifact and records these gaps. The publish job refuses to create a GitHub Release while any shipped component is still open. Intel mpv's source tarball is produced only when that packaging job runs; publish accepts it only when the archive contains `build-intel-mpv.sh`, `intel-mpv-sources.json`, `mach-minos.py`, and `mach-deps.py`.

Replacing the open macOS binaries does not need a new supplier. Retarget `scripts/release/build-intel-mpv.sh` and `intel-mpv-sources.json` (FFmpeg 7.1.1, libplacebo 7.349.0, libass 0.17.3) to arm64 with `MACOSX_DEPLOYMENT_TARGET=14.0`, and use that prefix for the macOS ffmpeg/ffprobe sidecar instead of Martin Riedl. Intel stays at deployment target 12.0. Windows official mpv still needs its own pinned build: v0.41.0's `ci/build-win32.ps1` clones shaderc at `HEAD` and sets Vulkan `UPDATE_DEPS=ON`. This change does not rewrite those platforms. Publication stays refused until those closures exist.
