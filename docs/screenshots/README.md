# Interface captures

These are actual captures of the current frontend in Chromium at 1200×800 CSS pixels,
with reduced motion and an empty library. No personal media or fabricated library data
is included. They demonstrate interface appearance and language switching, not native
window vibrancy, playback, or installer execution.

- `my-wave-en.png`: My Wave, English, Aurora Night.
- `settings-ru.png`: Appearance settings, Russian, Light.

To refresh, run `npm run dev`, open the frontend in a browser, select My Wave, and change
language/theme through Settings. Capture the app viewport after controls settle. Use
native macOS captures later to document platform window materials; label the platform
and version rather than presenting browser captures as native desktop screenshots.
